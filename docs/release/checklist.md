# Smoke-чек-лист перед публикацией

Прогоняется на **чистом пользователе macOS** (не на разработческом аккаунте) с DMG, **скачанным через браузер**. Всё, что проверено на машине разработки, здесь не считается: там уже есть сертификаты, разрешения, настройки и привычки.

## 1. Установка

- [ ] DMG открывается двойным кликом без предупреждений Gatekeeper.
- [ ] Перетаскивание в Applications работает, окно DMG объясняет это без инструкции.
- [ ] Первый запуск — без диалога «приложение загружено из интернета, вы уверены».
- [ ] Иконки в доке нет, иконка в меню-баре есть.

## 2. Онбординг

- [ ] Экран совместимости показывает **живой угол** этой машины.
- [ ] Калибровка: «push the lid until it stops» → записан максимум, число правдоподобно.
- [ ] Пропуск калибровки → зона упора выключена, и в настройках видно почему.
- [ ] Предупреждение про Zoom видно и читается, а не спрятано мелким шрифтом.
- [ ] Launch at login включается; System Settings ▸ General ▸ Login Items показывает Ajar. (`sfltool dumpbtm` для этого не годится — виснет без Full Disk Access, проверено в Block 07.)
- [ ] Повторный запуск онбординг не показывает.

## 3. Основной жест (Free)

- [ ] Прикрыть крышку ниже порога → микрофон замьючен (проверить в System Settings ▸ Sound ▸ Input).
- [ ] Открыть → микрофон вернулся.
- [ ] Микрофон был выключен пользователем до жеста → после цикла остался выключенным.
- [ ] Быстрое хлопанье крышкой в пределах секунды не вызывает действий.
- [ ] Задержка от жеста до мьюта не ощущается на глаз.

## 4. Подавления

- [ ] Закрыть крышку полностью → уснуло, при открытии никаких лишних действий.
- [ ] Внешний монитор + закрытая крышка → ничего не срабатывает. Отдельной строки в попапе про это нет намеренно: clamshell-кода в продукте нет, закрытая крышка — это зона `closed`, где действий не бывает (замер 2026-08-12, `docs/research/clamshell-2026-08-12.log`).
- [ ] Автозапуск при логине с прикрытой крышкой → в первые секунды ничего не происходит.
- [ ] Тумблер паузы → жест выключен, живой угол продолжает обновляться.

## 5. Pro

- [ ] Триал активен, показан честно, без обратного отсчёта.
- [ ] Толчок до упора запускает назначенный Shortcut.
- [ ] Удалённый шорткат → внятная ошибка, приложение живо.
- [ ] Истёкший триал → зона упора **продолжает работать** дефолтным Do Not Disturb, задизейблен только выбор своих шорткатов; встроенный мьют и все пороги работают.
- [ ] Покупка тестовым ключом: страница оплаты открывается из пейволла, ключ активируется, Pro включается, перезапуск сохраняет состояние.
- [ ] Отключить сеть, перезапустить → остаётся Pro. (Проверка формальная: сетевого кода в лицензировании нет вообще.)
- [ ] Мусор вместо ключа и ключ с чужой подписью → два разных внятных сообщения. Лимита активаций у нас нет, и сообщения про него быть не должно.

## 6. Обновление

- [ ] Установить предыдущую версию, подложить appcast с новой → Sparkle находит, ставит, перезапускается, настройки и лицензия на месте.
- [ ] Настройки ▸ About ▸ «Check for Updates…» на актуальной версии → «You're up to date», окно выходит на передний план, а не прячется за чужими (`LSUIElement`).

## 7. Удаление

- [ ] Перетаскивание в корзину убирает приложение; login item снимается; микрофон не остаётся замьюченным навсегда.

Последний пункт важнее, чем кажется: приложение, которое после удаления оставило микрофон выключенным, порождает багрепорт от человека, который уже не может его прочитать в нашем интерфейсе.
