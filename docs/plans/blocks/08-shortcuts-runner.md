# Block 08 — Shortcuts runner (Pro)

Зависимости: 07.

## Задача

Превратить крышку в программируемый контроллер: любой переход зоны запускает выбранный пользователем Shortcut. Это вся Pro-ценность и вся замена приватным API из первой редакции плана (Focus, пауза музыки, яркость — всё сюда).

## Объём

- `Ajar/Actions/ShortcutRunner.swift`:
  - Перечисление доступных шорткатов (`shortcuts list`), кэш на время жизни окна настроек.
  - Запуск по имени. Выбрать один из двух путей по факту замера задержки: `Process` на `/usr/bin/shortcuts run <name>` либо `NSUserAppleScriptTask`. Замер обязателен, результат — в STATUS.md.
  - Запуск асинхронный. Висящий шорткат не блокирует реакцию на следующее движение крышки; параллельные запуски одного и того же шортката подавляются.
  - Ошибка (шорткат удалён, переименован, вернул ненулевой код) пишется в лог и показывается строкой в попапе — молча не проглатывать, иначе пользователь будет думать, что сломался датчик.
- Модель привязок: `[ZoneTransition: ShortcutName]` в `UserDefaults` — отдельно вход и выход для каждой зоны, включая `stop`.
- UI в настройках, вкладка Zones: под каждой зоной два поповера выбора шортката (on enter / on exit). В Free вкладка видна, но выбор задизейблен с кнопкой «Pro».
- Зона `stop` активируется только при наличии Pro и откалиброванного `maxAngle`.

## Ручной чек-лист (на реальном железе, результат в STATUS.md)

1. Шорткат «включить Focus» на вход в `stop`: толчок до упора включает Focus, возврат выключает.
2. Замер задержки от жеста до эффекта, отдельно для обоих путей запуска. Записать оба числа.
3. Удалённый шорткат → внятная ошибка в попапе, приложение живо.
4. Быстрая серия жестов не порождает очереди из накопившихся запусков.

## Acceptance

- Unit-тесты модели привязок (сериализация, переход без привязки, подавление параллельного запуска) — сам вызов Shortcuts не мокать.
- Чек-лист пройден, обе задержки записаны в STATUS.md.
- Если задержка окажется больше ~700 мс и жест начнёт ощущаться вялым — остановиться и обсудить с владельцем возврат к встроенным действиям (это записано как риск в PRODUCT.md).
