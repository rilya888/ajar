# Block 03 — Zone engine + calibration

Зависимости: 02.

## Задача

Превратить поток градусов в события «вошёл в зону» / «вышел из зоны». Это сердце продукта и самая тестируемая его часть — здесь не должно быть ни одной строки, требующей железа.

## Объём

- `Ajar/Zones/Zone.swift` — `enum Zone { case closed, low, normal, stop }`.
- `Ajar/Zones/Calibration.swift` — `Codable`-структура из ARCHITECTURE.md (`maxAngle`, `closedBelow`, `lowThreshold = 45`, `hysteresis = 2`, `dwell = 1.0`, `stopMargin = 2`), хранение в `UserDefaults`, значения по умолчанию — из замеров Block 01.
- `Ajar/Zones/ZoneEngine.swift` — **чистая** `static func zone(angle: Int, previous: Zone, calibration: Calibration) -> Zone`. Гистерезис применяется только на выход из текущей зоны: сидя в `low`, зона держится до `lowThreshold + hysteresis`; сидя в `normal`, в `low` переходим на `lowThreshold`.
- `Ajar/Zones/ZoneTracker.swift` — слой удержания: смена зоны фиксируется, только если новая зона продержалась `dwell` **и** угол за это окно изменился меньше чем на 3°. Второе условие не опционально: замер показал, что при полном закрытии крышка проходит зону `low` за 1,28 с, и одного `dwell` мало — обычное закрытие ноутбука мьютило бы микрофон на 0,3 с. Выдаёт `ZoneTransition { from, to, at }`. Время — параметром (`now: Date`), не `Date()` внутри, иначе не тестируется.
- `Ajar/Zones/CalibrationSession.swift` — замер максимума: наблюдает угол 3 с, берёт максимум, пишет в `Calibration.maxAngle`. Отклоняет замер, если максимум < 90° (крышку не толкнули) — с честной ошибкой, а не молча.

**Никакого сглаживания.** Замеры дали нулевой шум в покое; скользящее среднее из первой редакции плана добавляло бы только задержку. Если на другой модели шум найдётся — добавлять тогда, здесь оставить `// ponytail:`-комментарий с этим объяснением.

## Ручной чек-лист

1. Живой лог зон при медленном закрытии: ровно один переход `normal → low`, без дребезга на границе.
2. Толчок крышки до упора даёт ровно один `→ stop`; возврат в рабочее положение — ровно один `stop → normal`.
3. Быстрое хлопанье крышкой в пределах секунды не порождает действий (работает `dwell`).

## Acceptance

- Unit-тесты (без железа, синтетические последовательности углов): все переходы между четырьмя зонами; гистерезис в обе стороны на каждой границе; `dwell` — зона держится / зона не додержалась / зона сменилась дважды внутри окна; **реальная последовательность полного закрытия из `docs/research/closed-test.log` (110→…→46→…→4→0 за 2,6 с) не должна породить ни одного перехода в `low`** — это регрессионный тест на дефект, найденный замером; калибровка (валидный замер, отказ при < 90°, `stop` недостижим при некалиброванном `maxAngle`); вырожденные калибровки (`lowThreshold` выше `maxAngle`, `closedBelow` выше `lowThreshold`) не должны вешать движок.
- Чек-лист пройден, результаты в STATUS.md.
