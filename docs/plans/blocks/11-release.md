# Block 11 — Release: Developer ID, notarization, Sparkle

Зависимости: 08, 09, 10.

## Задача

Превратить сборку в приложение, которое чужой Mac открывает без предупреждений и обновляет само.

Блок не начинать, пока владелец не закрыл в `docs/TODO.md`: Apple Developer Program ($99/год), выбор провайдера лицензий, решение по имени и домену, иконка.

## Объём

- **Иконка** (`Ajar/Resources/Assets.xcassets/AppIcon.appiconset`) — 10 PNG, mac-идиома. SF Symbols в иконках приложений запрещены лицензией Apple: рисовать путями или получить от владельца.
- **Подпись:** Developer ID Application, Hardened Runtime, `--timestamp`, `--options runtime`. Sandbox остаётся выключенным.
- **Нотаризация:** `xcrun notarytool submit --wait` по ключу App Store Connect API, затем `xcrun stapler staple`. Скрипт целиком — в `Tools/release.sh`, воспроизводимо, без ручных шагов в Xcode.
- **DMG:** фон с одной подсказкой «перетащите в Applications», подписан и нотаризован отдельно от `.app`.
- **Sparkle** (единственная разрешённая сторонняя зависимость, SPM): EdDSA-ключ, `appcast.xml`, `SUFeedURL`, автопроверка раз в сутки. Приватный ключ **не** в репозитории — в Keychain владельца, инструкция в `docs/release/submission.md`.
- **Лендинг** (`docs/site/`): одна страница, главный элемент — гифка жеста; таблица совместимости; предупреждение про Zoom тем же текстом, что в онбординге; страницы Privacy и Support (обязательны для провайдера платежей).
- **Проверка на чистой машине/пользователе:** скачивание DMG из браузера, открытие без обхода Gatekeeper, первый запуск, онбординг, покупка тестовым ключом, обновление через Sparkle с предыдущей версии.

## Ручной чек-лист

1. `spctl -a -vvv Ajar.app` → `accepted, source=Notarized Developer ID`.
2. DMG скачан через браузер (не скопирован), открыт на чистом пользователе → ни одного предупреждения Gatekeeper.
3. Sparkle: подложить appcast с версией выше, приложение находит обновление, ставит, перезапускается.
4. Полный smoke на чистом пользователе: онбординг → калибровка → жест → мьют → покупка → Pro-жест.
