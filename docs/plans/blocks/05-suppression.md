# Block 05 — Suppression & lifecycle

Зависимости: 03.

## Задача

Собрать в одном месте все причины «сейчас ничего не делать». Без этого блока приложение выключает микрофон, когда человек просто закрывает ноутбук и уходит домой, — и это самый быстрый способ получить возврат денег.

## Объём

- `Ajar/Lifecycle/Suppressor.swift` — чистая `isSuppressed(state: SuppressionState) -> Bool` плюс тонкий сборщик флагов:
  - **Clamshell — сначала проверить, нужен ли.** Замеры показывают, что закрытие ноутбука с внешним монитором безопасно и без кода: зона `closed` действий не выполняет, проход через `low` отсекается требованием стабильности угла. Прогнать пункт 1 чек-листа **до** написания кода; если ложных срабатываний нет — не писать ничего и записать это решение в STATUS.md. Если есть — признак «крышка закрыта И среди активных дисплеев есть не-встроенный» (`CGDisplayIsBuiltin` по `NSScreenNumber`). Признак «система не спит» не использовать: замер показал машину, бодрствующую 3,5 минуты с закрытой крышкой без всякого монитора.
  - **Сон:** `NSWorkspace.willSleepNotification` → подавление; `didWakeNotification` → подавление ещё 3 с. Не из-за датчика — он после сна отдаёт корректное значение сразу, — а потому что на пробуждении крышка по определению проходит зону `low`.
  - **Стартовая пауза:** первые 3 с после запуска. Иначе автозапуск при логине с прикрытой крышкой сразу что-нибудь сделает.
  - **Глобальный тумблер:** пользователь поставил Ajar на паузу из попапа. Персистится в `UserDefaults`.
  - **Зона `closed`:** закрытие крышки — не жест, никаких действий.
- Подавление гасит именно действия, а не чтение датчика: живой угол в UI продолжает обновляться, иначе пользователь решит, что приложение зависло.
- Выход из подавления **не** запускает отложенные действия. Если крышку прикрыли во сне, при пробуждении мы ничего не мьютим — состояние зоны пересчитывается заново.

## Ручной чек-лист (на реальном железе, результат в STATUS.md)

1. Внешний монитор подключён, крышка закрывается → микрофон НЕ мьютится, приложение не реагирует. (Нет монитора — пункт уходит в TODO владельцу.)
2. Крышка закрывается без внешнего монитора → машина уснула, при открытии никаких лишних действий, состояние микрофона не изменено сном.
3. Автозапуск при логине с прикрытой крышкой → в первые секунды ничего не срабатывает.
4. Тумблер «пауза» в попапе → жест перестал работать, живой угол продолжает обновляться.
