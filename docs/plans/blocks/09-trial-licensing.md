# Block 09 — Trial + licensing + paywall

Зависимости: 07.

## Задача

Триал, лицензионный ключ и гейт Pro. Вне App Store всё это своё: StoreKit недоступен, вместо него — Paddle и ключ, который пользователь вводит руками.

Провайдер выбран — **Paddle**. Перед стартом блока владелец обязан ответить на один вопрос: аккаунт Classic или Billing. От этого зависит схема (`docs/release/licensing.md`): встроенные ключи с онлайн-активацией у Classic либо офлайн-проверка подписи Ed25519 у Billing. Без ответа блок не начинать — это разные реализации `LicenseManager`, а не разные константы.

## Объём

- `Ajar/Licensing/Tier.swift` — `enum Tier { case trial(daysLeft: Int), free, pro }`, единственный источник правды для гейтов. Свойство `hasPro`.
- `Ajar/Licensing/TrialManager.swift`:
  - Дата первого запуска в файл в Application Support **и** в `UserDefaults`; при вычислении берётся более ранняя из двух. Нет ни одной — сегодня, пишется в обе сразу.
  - `tier(now:hasLicense:)` — лицензия приоритетнее истёкшего триала; `daysElapsed < 14` → `.trial`, иначе `.free`.
  - // ponytail: перевод часов назад обманет триал — принимаем, цена вопроса $9
- `Ajar/Licensing/LicenseManager.swift` — одна из двух реализаций по ответу владельца:
  - **Офлайн (Paddle Billing):** ключ = `base64(payload).base64(sig)`, проверка `Curve25519.Signing.PublicKey.isValidSignature` встроенным публичным ключом, результат в Keychain. Сетевого кода нет вообще. Ошибки: неразбираемый ключ, неверная подпись — два внятных сообщения.
  - **Онлайн (Paddle Classic):** активация одним HTTP-запросом, кэш в Keychain, повторная проверка не чаще раза в N дней и **никогда не блокирующая** — нет сети, остаёмся Pro. Деактивация из настроек, три активации на ключ. Ошибки различаются: неверный ключ, исчерпан лимит (сказать сколько и предложить деактивировать), нет сети (предложить повторить).
- `Ajar/UI/PaywallView.swift` — одно окно: что даёт Pro, цена, кнопка «Buy» (открывает страницу оплаты в браузере), поле ввода ключа, «Restore» = повторная активация тем же ключом. Без обратных отсчётов и искусственной срочности.
- Гейты: зона `stop` и выбор шорткатов доступны при `tier.hasPro`. Встроенный мьют и все пороги — всегда.
- Строка апселла в попапе по спеке из PRODUCT.md; при пустой статистике — нейтральный вариант.

## Ручной чек-лист

1. Чистый запуск → `.trial(14)`; подмена даты первого запуска на 15 дней назад → `.free`, зона `stop` и шорткаты задизейблены.
2. Ввод боевого ключа (тестовый режим Paddle) → `.pro`, гейты сняты, перезапуск сохраняет состояние.
3. Отключить сеть, перезапустить → остаётся `.pro`.
4. Ошибочные пути дают разные внятные сообщения (набор зависит от схемы).

## Acceptance

- Unit-тесты: граница 14 дней (13 дней → `.trial(1)`, ровно 14×86400 → `.free`), приоритет лицензии над истёкшим триалом, отсутствие обеих меток = сегодня, более ранняя из двух дат побеждает, разбор всех веток ответа API (по зафиксированным JSON-фикстурам, сеть не дёргать).
- Чек-лист пройден, результаты в STATUS.md.
